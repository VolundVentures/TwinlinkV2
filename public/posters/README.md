# Landing page poster images

Drop still frames here, matching the filenames under `public/videos/` (but with `.jpg`):

- `hero.jpg`, `split.jpg`, `closing.jpg`
- `film-01.jpg` … `film-06.jpg`

Posters render before the video plays (hero/split/closing autoplay; reel tiles
play on hover). Any missing poster simply falls back to the gradient — no layout
break.
